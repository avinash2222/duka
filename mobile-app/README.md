# DUKA mobile app

React Native (Expo) app for **customers**, **delivery agents**, and **vendors**. Operator and back-office tools are separate packages in the repo (see `PROJECT-SPEC.md`).

**Rename this folder to `mobile/` (optional):** Close Expo/Metro and editors using this path, then from the repo root run:

`powershell -ExecutionPolicy Bypass -File scripts/rename-frontend-to-mobile.ps1`

(or `git mv Frontend mobile`).

Before coding a new feature, create or update its docs in:

`docs/features/<feature-slug>/`
