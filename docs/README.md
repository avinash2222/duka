# DUKA Documentation Hub

This folder holds detailed documentation that supports AI-first development.

## Structure

- `docs/features/` — One folder per feature with a single `feature.md`.
- `docs/authentication/` — Cross-client integration specs (mobile, admin, backend), e.g. user creation and OTP-related contracts.
- `docs/templates/` — Reusable templates for consistent documentation.

## Documentation policy

- Keep high-level product direction in `PROJECT-SPEC.md` (repository root).
- Keep implementation detail in feature-level docs under `docs/features/`.
- Create or update feature docs before implementation starts.
